# Reproduced results

Generated by `python examples/reproduce_paper.py --public-dbt`. Environment: git git version 2.47.3, platform Linux-6.12.113+-x86_64-with-glibc2.41, python 3.13.5, sqlite 3.46.1, tokenizer_exact True.

**Read this first.** The paper's numbers were measured with the authors' original
harness on the public dbt Jaffle Shop history. This repository is a clean
re-implementation from the paper's text. The synthetic replay runs on a generated
project, so its counts are *not expected to equal* the paper's; they show the same
behaviour (dedup dominates, every rule fires, all as-of and rebuild checks pass,
repeats are identical). The public-dbt column re-runs the same pipeline on the
same public project, but our harvester's scope (which YAML entries become
concepts) is our own reading of the paper, so counts differ; see
docs/design-notes.md.
